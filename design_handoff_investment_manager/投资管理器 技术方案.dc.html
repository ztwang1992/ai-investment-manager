怎么做成真正的 App

网页 App（PWA）用 Claude Code 开发，部署在 Cloudflare，数据放 Supabase 的新加坡区。整套免备案，只用免费额度，国内能访问但速度一般。

整体架构

手机 PWA React + Vite · 添加到主屏幕 · 本地缓存（IndexedDB），离线也能看
⇄
Cloudflare Pages托管网页，全球 CDN
Cloudflare Worker行情与汇率中转，统一格式，结果缓存 15 分钟
Supabase · 新加坡邮箱登录 · Postgres 数据库 · 行级权限，每个人只能看自己的数据
→
外部数据 免费接口 美股价格 · A 股 / 场外基金净值 · 汇率。具体数据源开发时验证

手机只和 Cloudflare、Supabase 通信，不直接调外部接口。外部接口失效时只改 Worker，App 不用动。
