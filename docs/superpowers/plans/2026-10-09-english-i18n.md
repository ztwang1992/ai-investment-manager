# English Version with Chinese Localization — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make English the source language of the project:
- the app UI, with Simplified Chinese as a complete translation;
- the living docs;
- the code comments.

The default language follows the device. A switch in settings overrides it.

**Architecture:**
- **Message modules.** Copy lives in message modules under `src/i18n/messages/`, one per feature, with English and Chinese side by side (`export const zh: typeof en`). `src/i18n/index.ts` composes them into `MESSAGES: Record<Locale, Messages>`. TypeScript enforces that Chinese has every key, with the same function signatures. Interpolation and plurals are plain functions. No new dependency.
- **Where the locale lives.** `locale` sits in the app store and is a device setting, not synced. Its initial value is a saved override from localStorage, otherwise `navigator.languages[0]`: `zh*` gives Chinese, anything else English. `<html lang>` and `document.title` follow it.
- **Access.** Components use `useT()`. Code outside React uses `currentMessages()`. Every message set carries its own `locale`, which callers pass to the formatters.

**Tech Stack:** React 19, Zustand, TypeScript. No new dependencies.

**Spec:**
- `design_handoff_investment_manager/README.md` (Chinese) for behavior and copy;
- the user's decisions below for language.

## Decisions (user, 2026-10-09)

1. **Scope.** English for the UI, the living docs (CLAUDE.md, DEPLOY.md, docs/supabase-setup.md, docs/worker-setup.md) and all code comments. The historical records stay in Chinese:

2. **Default language** follows the phone's system language. A switch in settings overrides it and is saved on the device.
3. **Instrument names.** In the English UI, A-share and Chinese fund names keep their Chinese names, because they are product names. Asset classes, groups and US-listed instruments get English names.
4. **Order.** Finish the English version first, then publish. README screenshots come in both languages.

## Design rules

- **Stored data keeps its Chinese values.** No migrations. This covers:
  - the market enum (美股 / A股 / 场外基金 / 现金);
  - system remarks on records and calibration reasons;
  - preset names.

  The code refers to these values only through named constants:
  - `MARKET` in `src/domain/types.ts`;
  - `REASON` and `CALIBRATION_REASON` in `src/domain/record.ts`.

  The UI translates them for display.
- **Preset names.** A preset's name (group, asset, instrument) shows translated only while the stored name still equals the original Chinese preset name. A renamed preset or a user-created name is shown as typed. Chinese is the identity mapping.
- **UI-only identifiers move to English:**
  - performance ranges (`RangeKey`: `1w 1m 3m 1y 3y 5y all`);
  - record time filters (`RecordTime`).
- **Domain functions return error codes, not sentences.** The UI maps each code to a message.
- **Formatting follows the locale.** `formatAmount`, `formatMoney` and `formatSignedAmount` take the locale:
  - Chinese keeps 万 for CNY and HKD, and K/M for USD (as in the prototype);
  - English uses K/M for every currency.
- **Sample data follows the locale:**
  - account names;
  - the AI sample conversation.
- **The AI advisor follows the locale:**
  - system prompt, portfolio summary, suggestions and status messages;
  - the prompt tells the model which language to answer in.
- **Exports follow the locale:** the CSV header and type names. The JSON backup's `app` field becomes the identifier `invest-manager`.
- **Tone in both languages:** calm and concise. English uses sentence case and no exclamation marks.
- **Guard test.** Chinese may appear in non-test source only in:
  - the zh messages;
  - the stored-value constants;
  - the preset and sample catalogs;
  - worker test fixtures.

  A test enforces this.

## Review Focus

1. **Copy that bypasses the messages** (an inline string left in a component). The guard test fails on any CJK outside the allowed files.
2. **Switching language at runtime.** Every visible string and number format updates without a reload, and the current tab is kept.
3. **Existing data in English.**
   - Records with Chinese system remarks and Chinese preset names display in English.
   - Renamed presets keep the user's name.
   - A user's own remarks are shown as typed.
4. **AI advisor in English.** The summary and prompt are in English and ask for English answers; in Chinese they ask for Chinese.
5. **Long English strings at 375 px.** Check every tab and sheet in the browser for overflow and awkward wrapping.
